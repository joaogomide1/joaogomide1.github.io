Pipeline ETL de clima

Extract

Chama a API pública Open-Meteo para São Paulo, Rio de Janeiro, Brasília, Salvador e Manaus: temperatura máxima, mínima e chuva dos próximos 7 dias.

Transform

Converte o JSON aninhado em tabela, renomeia colunas, corrige tipos, trata nulos, cria temperatura média e a coluna "vai chover" e remove duplicatas.

Grava no SQLite de forma idempotente (rodar de novo substitui os dados) e valida com uma consulta SQL de média e chuva por cidade.

 Inteligência Computacional (IC) · UFG

Algoritmo genético · Função F6

Codificação

Cada indivíduo tem 44 bits: 22 para x e 22 para y, convertidos para o intervalo de −100 a 100.

Evolução

Seleção por roleta, cruzamento de um ponto (65%), mutação bit a bit (0,8%) e elitismo: o melhor de cada geração passa direto.

Resultado

F6 = 0,9628 em 40 gerações com semente 42. Em outro experimento, com 400 gerações, chegou a cerca de 0,99. O máximo é 1,0.

def funcao_f6(x, y):
    r2 = x * x + y * y
    num = math.sin(math.sqrt(r2)) ** 2 - 0.5
    den = (1.0 + 0.001 * r2) ** 2
    return 0.5 - num / den
